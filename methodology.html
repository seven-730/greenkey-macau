§ 0适用性与核算边界

方法学编号
GKM-01 / Operational-Attributable Reduction（OAR）
适用主体
澳门持牌小型酒店、经济型酒店、公寓式酒店、青年旅舍与小型持证餐饮场所
核算边界
外购电力（Scope 2，位置基准）· 门店级 · 不含燃料、制冷剂、物流与差旅
计量周期
以"计费日"为单位（默认 28 日观察窗口），最短可至 15 分钟聚合
活动量单位
住宿业：入住间夜 / 床位夜；餐饮业：到店客次
产出物
避免用电量（kWh）、避免排放量（tCO₂e）、单位活动量强度改善（%）
不适用
企业级年度碳盘查、产品碳足迹、碳信用（offset）签发

本方法学只回答一个问题：在给定的计费日内，当住客数量与当天实际一致时，这家店的用电量相对"什么都没做"的反事实减少了多少。 它不试图回答"这家企业总共排放了多少"，也不产出可用于抵消的碳信用。

边界刻意收窄到电表能证明的部分。企业级盘查需要处理燃料、制冷剂、采购商品与员工通勤；小微商户没有能力提供这些数据，强行纳入只会让结果更不可信。

§ 1术语定义

术语定义
日型工作日 / 周末 / 公众假期。澳门的用电结构由日型驱动，而非传统淡旺季。
历史常态近 12 个月同类型日的历史均值，包含当时的入住率水平。回答"这种日子通常用多少"。
校正 BAU把历史常态按当日实际活动量换算后的期望用电。回答"今天住这么多人，正常该用多少"。
活动量效应入住率/客数变化引起的用电变化。真实存在，但不计入减排，因为不是效率改善。
强度效应（OAR）在相同活动量下，单位能耗下降带来的节电量。这是唯一被核证的部分。
未干预窗口措施上线前、且无重大经营变更的连续计费日，是基线唯一的训练数据来源。
满年化按年度日型构成（工作日 250 / 周末 96 / 假期 19）外推的年减排量，仅用于潜力展示与授信测算。

§ 2双轨基线模型

对每个计费日 d，模型同时给出两条基线：

Eexp(d) = Base · W(d) + Anorm(d) · I0 · W(d)　　← 历史常态 Ebau(d) = Base · W(d) + Aact(d) · I0 · W(d)　　← 校正 BAU
  • Base：每日基载（公区、厨房、电梯、热水），不随入住率线性变化；
  • Anorm：按历史常态入住率推算的活动量；Aact：当日实际活动量；
  • I₀：单位活动量基准能耗（kWh / 间夜或客次）；
  • W(d)：气候修正系数，由冷却度日 CDD（18℃ 基准）线性映射。

两条线的差值 Eexp − Ebau 就是活动量效应。把它从"改善"中扣掉， 剩下的 Ebau − Eact 才是可以被归因的强度效应。 这一步是本方法学与所有"历史均值基线"做法的分水岭。

训练窗口规则

  1. 仅使用未干预窗口的数据，措施上线后的观测值永不回流进基线；
  2. 窗口不少于 6 个计费周期；不足时使用业态先验并自动放宽置信区间（见 §6 C 级）；
  3. 每 12 个周期滚动重训一次，保留历史版本以便复算；
  4. 检测到结构性变更（扩建、换设备、营业时间重大调整）时，重训并从下一周期重新起算；
  5. 历史常态采用固定基准年而非滚动窗口，避免"长期低入住率把基准拉低"的漂移。

§ 3归因规则

以下五条规则按顺序执行，任一条件不满足则该计费日不计入 OAR。

R1 · 活动量校正

BAU 必须以当日实际活动量换算。未校正的差值一律视为活动量效应，不进入归因池。

R2 · 置信门槛

Eact(d) < 0.94 · Ebau(d)（P10 置信下界），且连续 ≥ 2 个计费日满足。单日偶发不计入。

R3 · 计量口径

归因额 = Ebau(d) − Eact(d)。不采用上限估计，避免系统性高估。

R4 · 缓冲与剔除

措施上线当日为缓冲日，不计入；停电、施工、停业区间整段剔除，不插值、不外推。

R5 · 措施溯源

措施时点以运维工单、门磁或采购记录为准，不以企业申报为准。无记录的"措施"不产生证书。

§ 4计算公式

OAR = Σd ∈ D max( 0 , Ebau(d) − Eact(d) ) · 1[ Eact(d) < 0.94 · Ebau(d) ] 强度改善 = 1 − ΣEact / ΣEbau　（按活动量加权） 活动量效应 = ΣEexp − ΣEbau　（明确排除，不进入证书） tCO₂e = OAR × EF / 1000 EF = 0.50 kgCO₂e/kWh（澳门电网参考值，按核证年度官方披露更新）

其中 D 为满足 R1–R5 的计费日集合。排放因子在证书中冻结为签发时的取值与来源版本； 若后续官方更新，仅影响新签发的证书，不影响存量。

绿信分

GCS = 300 + 700 × ( 0.50·S₁ + 0.18·S₂ + 0.17·S₃ + 0.15·S₄ ) S₁ = min( 1 , 强度改善 / 18% ) S₂ = min( 1 , 连续核证月数 / 18 )　（须存在可归因减排，否则为 0） S₃ = Σ 数据源权重（电表 .38 / 账单 .24 / 入住率 .24 / 工时 .14） S₄ = 0.6 × 第三方复核 + 0.4 × 公开披露

S₁ 的分母 18% 取自本方法学在六业态上测算出的强度改善上限，用于把不同体量的门店放到同一把尺子上。 S₃ 与 S₄ 是对"证据强度"的定价，而不是对"减排量"的定价。

§ 6数据质量分级

等级数据条件置信区间可用途
A智能电表 + 账单 + 入住率 + 工时（四源齐备，≥ 12 个周期）±6%信贷、贴息、认证申报
B三源齐备，或四源但周期 < 12 个周期±9%信贷（额度下调）、贴息
C仅有账单，或使用业态先验的冷启动±15%仅贴息材料、内部管理

置信区间直接决定 R2 的门槛高度：B 级证书的 P10 下移，C 级进一步下移，因此同一家店在数据不足时会得到更小的 OAR。 这是"证据不足就要少算"的机械实现，不依赖人的判断。

§ 7保守性原则

当存在多种可行的计算路径时，本方法学一律选择产生较小 OAR 的那一条。具体体现为：

  • 用校正 BAU 而非历史常态作被减数（先扣掉活动量效应）；
  • 用 P10 而非 P50 作门槛；
  • 措施效果按独立事件相乘合并，天然处理重叠与衰减，不用简单加总；
  • 缓冲日与爬坡期照常计入实测，但不做满年化外推；
  • 结构性变更后重新起算，不追溯继承历史效果。

代价是可核证量通常只有"账单降幅"的 55–65%。这是有意为之：一份能被银行采信的小数字，胜过一份没人敢用的大数字。

§ 8与既有标准的关系

本方法学在结构上参照通行的节能量与减排量核算框架，但不宣称符合或获得任何标准的认证。对应的位置如下：

参照文件借用的部分差异
GHG Protocol · Scope 2 Guidance外购电力的边界划定与排放因子法不产出企业级清单，只产出单店避免量
ISO 50015（节能量测量与验证）基线设定、调整与不确定性处理的一般原则以统计置信区间替代工程计算法
ISO 14064-2（项目层面减排）额外性、基线情景与监测计划的思路不做项目注册，不做抵消签发
CDM 方法学（AMS-II.C 等）小规模能效项目的简化处理颗粒度到单店单日，规模远小于 CDM 门槛

目标是在试点结束后，与本地认证机构共同提交一份可在澳门适用的行业方法学草案，并争取被纳入绿色信贷的操作指引。 在那之前，任何"已获认证"的表述都不成立。

§ 9已知局限

以下是我们目前做不到、或者做不好的事。列出来，是为了让使用者知道边界在哪里。

  • 日型分类依赖日历准确性。临时假期调整、跨年调休或大型活动期间的非常规营业，会造成日型误判；我们会在证书中标注"日历偏离"提示。
  • 基准漂移风险未被完全消除。若企业长期维持低入住率，滚动窗口会把基准拉低。因此历史常态固定采用基准年，但这意味着基准会随产业周期逐渐过时。
  • 只度量总量，不分解贡献。OAR 能告诉你"少了多少度"，但不能可靠地拆成"关楼层贡献多少、空调策略贡献多少"。分项计量可部分缓解，成本会上升。
  • 混合业态拆解不足。酒店带餐厅、旅舍带咖啡厅时，餐饮部分的活动量单位与住宿不同，目前的处理偏粗。
  • 无法处理非电减排。燃气炉具、制冷剂泄漏、食材采购都不在边界内，而这些在餐饮业并非小数目。
  • 仍存在策略性博弈空间。理论上企业可在基准年刻意维持高能耗。我们通过"固定基准年 + 同业横截面 + 变更点检测"三重约束提高成本，但无法完全消除。

一句免责：本方法学产出的是"避免排放凭证"，用于绿色金融与政府认证的材料支持， 不是可用于抵消的碳信用（carbon credit）。我们不参与自愿减排市场，也不为任何企业的碳中和声明提供依据。
